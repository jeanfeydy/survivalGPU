Getting started
================

survivalGPU is usable from both Python and R — pick whichever you're
working in:

- **Python**: :doc:`python/installation`, then the :doc:`python/user_guide/index`.
- **R**: :doc:`r/installation`, then the :doc:`r/user_guide/index`.

Both interfaces call into the same underlying computations (see
:doc:`index`), so the models and results are identical either way.
