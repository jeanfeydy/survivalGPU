survivalGPU
============

survivalGPU provides fast, GPU-accelerated implementations of Cox proportional
hazards and weighted cumulative exposure (WCE) survival models, available from
both Python and R. The R package delegates its computations to the same Python
backend via `reticulate <https://rstudio.github.io/reticulate/>`_.
