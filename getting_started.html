Getting started

survivalGPU is usable from both Python and R — pick whichever you’re working in:

  • Python: Installation, then the User guide.

  • R: Installation, then the User guide.

Both interfaces call into the same underlying computations (see survivalGPU), so the models and results are identical either way.
